# 原句发音与短语标注

用户于 2026-10-09 确认开始开发以下方案。

四六级及新概念学习、复习卡片的背面英文原句，复用已有 AIAnalysis；连读为浅蓝框、弱读为浅紫框、短语为浅绿框。发音与短语重叠时，发音颜色优先并加绿色短语下划线；同一位置兼具连读、弱读时用双色背景。标注区附颜色图例，文本提示展示来源说明。英文和空格原样保留，手机换行正常，学习卡片原有单词点击收藏继续可用。

个人中心设置增加总开关及三个独立开关，默认开启，沿用 cet-settings-store 本机持久化。关闭总开关不重置各子开关。关闭原句标注不隐藏下方解析面板。

匹配仅使用现有解析中的连续原句表达；下划线视为空格，提取箭头左侧及音标/括号前的英文，大小写和弯引号可归一化。完整单词边界匹配，不把 to 匹配到 today，不通过模糊匹配推断发音。多次出现的同一连续表达均标注；变形或非连续短语无法可靠定位时只保留下方解析，不强行标注。原句显示正常英文，不替换为音标或连读下划线。

解析被现有权限锁定时，原句不显示来源解析标注；解锁后生效。未标注卡片正常显示原句。复用 React 文本渲染，不注入 HTML。既有课程、素材、收藏和复习调度不改动。
