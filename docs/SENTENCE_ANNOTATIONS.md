# 原句发音与短语标注

个人中心 → 设置 → 原句标注，提供总开关、连读、弱读、短语三个独立开关，默认全部开启。总关闭保留子开关选择，刷新后保留本机浏览器设置；旧设置自动补齐默认值。

四六级及新概念学习和综合复习卡片的背面英文原句共用 AnnotatedSentence。连读浅蓝框、弱读浅紫框、短语浅绿框，短语与发音重叠时绿下划线；同时连读和弱读的重叠部分使用双色背景。图例带文字说明。标注单词的鼠标提示同时保留来源解析和收藏提示，键盘/鼠标收藏不触发翻卡。

标注来自现有 AIAnalysis，不自动诊断音频。匹配连续完整英文 token，处理下划线、音标后缀、括号和箭头说明，保留原句和标点；不进行词形或非连续模糊匹配。无法可靠定位的内容仍显示在下方解析面板。原句标注受既有解析解锁规则约束。
