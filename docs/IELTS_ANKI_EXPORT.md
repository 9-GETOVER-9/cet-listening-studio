# IELTS 第一章离线 Anki 导出

此工具完整导出当前本地 `ielts-reading-538-v1.json` 中的第一章词组，独立于网站运行。工具不修改词库、教材、网站练习记录或录音；不联网，不包含教材音频或其他媒体。

## 运行

需要 Python 3 和 `genanki`。当前工作环境已有 `D:\JIQIXUEXI\python.exe`，无需安装依赖。在项目根目录运行：

```powershell
D:\JIQIXUEXI\python.exe tools/export_ielts_anki.py --source public/data/ielts-reading-538-v1.json --output output/anki/ielts-reading-538-chapter1
```

也可从 Python 调用 `export_corpus(source: Path, output: Path)`，返回与 `manifest.json` 相同的字典。导入模块不会生成文件。导出前检查输入类型、状态、关系、来源 ID / 表达 ID 唯一性、完整表达列表及干扰项是否充足；无效输入会报错，尚未创建导出目录或修改其中的文件。重复运行会覆盖同名生成文件。

输出包含：

| 文件 | 内容 |
| --- | --- |
| `IELTS538-第一章完整牌组.apkg` | 三个类别的完整牌组 |
| `IELTS538-第一章第一类.apkg` | 第一类，含待核对资料子牌组 |
| `IELTS538-第一章第二类.apkg` | 第二类 |
| `IELTS538-第一章第三类.apkg` | 第三类 |
| `index.html` | 可离线浏览全部词条、核对多选、查看完整背面、下载牌组 |
| `manifest.json` | 源文件 SHA-256、实际数量、状态 / 类别 / 关系分布、牌组检查结果、每个来源 ID 对应的 note GUID |

教材 JSON 和整个 `output/` 目录均忽略于 Git。仅提交工具、模板、测试和本说明；不提交 APKG、SQLite 或教材文件。

## 卡片行为与待核对资料

卡片要求选择“书中列出的对应”，并标明关系：`lexical` 词语对应、`reference` 指代、`parallel` 并列、`contrast` 转折、`cause` 因果、`context` 语境。它不会把结构或语境关系一概称为同义词，也不判断表达在所有语境中是否等义。

普通卡包含该组全部正确表达，没有网站的四选项上限；最多的一组有 16 条来源表达。仅在多选选项中合并 Unicode NFKC、大小写和空白归一后重复的表达，背面始终保留完整原始列表。每组再加入两个来自其他非待核对词组的不同干扰项，排除本组所有已知对应与主词。干扰项选择及选项顺序按来源 ID 确定，重复生成相同来源时不改变顺序。

正面使用复选框、蓝色按钮和白色圆角卡片。未选时提示先作答；核对后选对显示绿色 `#dcfce7` / 边框 `#15803d`，错选与漏选显示红色 `#fee2e2` / 边框 `#dc2626`，同时显示文字标签。可“再练一次”。背面独立显示中文释义、完整原始对应、关系类型、来源 ID、状态与来源行，不依赖正面或 JavaScript 的执行结果。脚本为 ES5、每次渲染使用新闭包，也支持客户端注入脚本时 `document.currentScript` 为空的情况。

唯一待核对词组为 `fertiliser`，原始关系为 `context`。原始 `chemical / toxic / unnatural` 保留在参考背面，不标为正确答案；正面没有选择题、核对按钮或答案判断脚本。它保留第一类归属，单独放入 `IELTS538::第一章::第一类::资料待核对`，初次导入默认暂停。完成来源语境核实后，可在 Anki 浏览器中决定是否取消暂停。

核对选择不会自动给 Anki 打分或修改复习间隔。用 Anki“显示答案”后，仍由你按实际记忆选择“重来 / 困难 / 良好 / 简单”。不支持脚本的客户端可心中作答后查看静态背面；离线 HTML 在禁用脚本时会展示全部词条。

## 导入与更新

在 Anki 中导入完整牌组或所需类别包。类别包与完整包使用相同的 note GUID、模型和类别牌组 ID，导入两者不会按包名另造同一来源词组。

完整导出使用独立命名空间 `ielts-reading-538-chapter1-full-v1`。模型 ID 为 `1785369201`，根牌组 ID 为 `1785369210`，类别 ID 为 `1785369211` / `1785369212` / `1785369213`，待核对子牌组使用 `1785369221` / `1785369222` / `1785369223`。这些与先前单卡样例的命名空间和 ID 不同，因此完整包不会覆盖样例卡。

note GUID 仅由完整导出命名空间和来源 `id` 生成，不由主词或答案内容生成。纠正同一个来源 ID 的内容后重新导出，Anki 可匹配已有 note 并保留学习进度；导入时须允许更新现有笔记。不要为同一词组随意改来源 ID，也不要随意更改模型 ID、字段名或字段顺序。原有样例使用独立身份，会与完整牌组并存；如不再需要样例，可自行在 Anki 中移除样例牌组。
