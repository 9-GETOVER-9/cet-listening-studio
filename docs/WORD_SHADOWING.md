# 单词练习与新概念跟读

## 单词练习

雅思听力页面的王陆、高频与错词入口，及难点本的四六级/新概念词汇入口，使用 `/word-practice`。来源、章节、词汇层级、队列、题数和提示模式保留在地址中，返回来源后继续对应选择。

听音拼写使用雅思教材原音；难点本单词使用设备实际提供的英美英语合成声音，并可回听教材来源句。没有声音、音标或释义时显示真实缺失状态。可选词典补充只填缺失字段，不改变拼写答案。

首次错误与重拼结果分别保留。同轮重拼正确不清除正式错词，下一独立轮首次正确才清除。高频成绩、会话及操作凭据同库事务保存；难点本只更新 `fsrsNotebook`。看释义属于提示练习，不计正式高频掌握或每日正式听写数。每日计数由当天确认凭据计算，午夜与重新显示页面时刷新。

刷新恢复当前队列、答案和判定。上一词是只读回看。后台、输入法组合、笔记编辑、未完成保存或保存失败时暂停自动继续。实际未保存的批注与失败草稿保护全局导航；保存或明确丢弃后继续。离线难点本同步读取当前本机内容，删除与较新复习结果不被旧快照恢复或覆盖。

## 新概念跟读

新概念课程与原始句子卡片提供 `/nce/shadowing/:moduleId`，使用手机输入法语音输入或直接键入文字。默认看句跟读，可隐藏原句复述；教材原音仍可回听。个人录音回放禁用，显示“待开发”。核对结果属于文字内容正确率，不是发音评分。

预标记仅来自明确核对的姓名和地点别名，不根据首字母大写猜测。生成索引包含原句 SHA-256 和 UTF-16 位置；不一致时不沿用标记。原始标题和合并卡片不进入索引。用户可修改实际词段；自动预标记不保证穷尽所有姓名和地点。
