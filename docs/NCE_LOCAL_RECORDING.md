# 新概念个人录音（本地保存）

跟读页展开“个人录音 · 本地保存”，点击开始录音并允许麦克风，点击停止并保存。原句卡片的“个人录音回放 · 本地保存”入口定位到当前原句并展开录音区。

录音按当前账号或游客、原句存放在当前网站的独立 IndexedDB `nce-local-recordings` 中。每次录音保留一条，可回放、下载、删除；刷新不会主动删除。录音不进入学习云同步，也不上传 Git 或服务器。浏览器清理、存储回收、隐私模式关闭或换设备/浏览器可能无法恢复，下载是备份途径；文件保持浏览器实际格式（WebM/M4A/OGG）。网站更新沿用同一 HTTPS 域名及本地数据库。

手机输入法的语音转文字仍用于文字核对；网页录音单独申请权限，不取得输入法录音，也不评价发音质量。支持网页录音的 HTTPS 浏览器才显示开始按钮。权限拒绝、无设备或设备占用有中文提示。

申请权限、录制、保存及待重试录音期间暂停切句和自动继续，离开有拦截。切到后台时取消待授权请求，或自动停止已开始录制并保存；麦克风在结束、取消、错误及卸载时释放。保存失败保留本页 Blob，可重试、下载或丢弃。课程权限变为锁定时仍保留停止/保存/回放入口，禁止开始新的录音。个人回放与教材原音互斥。
