# 个人复习参数

入口：我的 → 设置 → 个人复习参数。听力主卡、难点本、雅思阅读 538 分别训练、应用和恢复默认。此功能在本地 feature/fsrs-personal-optimization 开发，未部署。

## 使用

1. 选择训练内容，刷新记录。旧听力日志没有账号标记，只有明确确认“本机旧评分均由我完成”后才纳入；不会认领其他账号标记的日志。
2. 可用数据达到门槛后点击“优化我的参数”；后台线程计算，可取消。
3. 页面显示独立验证集上的平均对数损失（越低越好）。候选需优于当前与默认参数，并改善训练损失，才显示“应用个人参数”。
4. 应用成功后使用个人参数；随时恢复默认。保存失败保留旧参数。

参数和训练数据均留在当前浏览器，不上传服务器。账号和游客分开，三个训练类型分开；参数不在现有 Supabase 同步及阅读备份中。换浏览器需重新优化，浏览器存储被清除时参数也会丢失。“清除学习数据”同时清除个人参数。

## 模型与优化方法

- 调度库：ts-fsrs 5.4.1；算法 FSRS-6，21 个权重。目标保留率仍为 90%，初学 1m/10m，重学 10m，启用 fuzz。
- 使用库的 FSRSAlgorithm.next_state 和 forgetting_curve 重放实际历史；日期差使用库的 dateDiffInDays（UTC 日期边界），与现有调度保持一致，跨日不等于满24小时。
- 优化器是本项目实现的有界坐标搜索，非 Anki/fsrs-rs 的反向传播优化器。采用平均二元对数损失与向默认参数收缩的正则项（0.001）；固定四轮步长 0.4/0.2/0.1/0.05；上下界来自当前 ts-fsrs 的 CLAMP_PARAMETERS。
- 按卡片分割：每5张卡片中1张验证、其余训练；同一卡片不会同时参与训练和验证。搜索只访问训练集，完成后一次验证；历史验证改善不保证未来改善，不宣称全局最优或与 Anki 优化结果一致。
- 初始产品门槛：20张完整卡片、100次跨日评分；训练集和验证集都必须有记住/忘记。此门槛是本项目的保守保护，不是 FSRS 官方最低样本数。
- 单次最多5000条评分，按完整卡片纳入，界面明确提示截取；不截断一张卡片的历史。当天复习保留用于状态重放，但不计入跨日预测损失。
- 应用/恢复只改变后续评分的模型，不批量改写已有 D/S 或到期时间；已有 D/S 是旧模型估计，会随后续评分更新。这是渐进生效模式，不等同 Anki 的全量记忆状态重算。

## 历史与边界

主卡新增 owner/beforeReps 元数据，评分/日志/同步任务同事务保存；已投递同步任务被删除后，重复 operationId 仍不重复评分。

难点本使用 IndexedDB v4 的 notebookReviews 表；常规评分和单词练习均与状态同事务保存。以前没有记录的历史不伪造；已有卡缺失初始历史时不用于训练，新卡逐步积累。

阅读沿用 owner 日志，排除 retry（重练不更新FSRS）；根据评分条数及最后时间与当前进度核对，备份导入缺失记录会被排除。

所有训练对象需匹配 reps、最后评分时间、可用评分和日期、唯一操作ID、新记录的 beforeReps；跨账号混用、同步缺口、未来时间、重复时间等不确定序列排除。旧日志无法独立证明身份，需用户确认。

## 代码入口

- fsrsOptimization.ts：纯数据校验、重放、评估和参数搜索。
- fsrsHistory.ts：本地三个训练来源。
- fsrsPreferences.ts：账号/类型隔离、本地参数校验与持久化。
- fsrsScheduler.ts：预览与正式调度共享参数选择。
- fsrsOptimizer.worker.ts / fsrsOptimizerClient.ts：后台计算、进度和取消。
- FSRSOptimizationPanel.tsx：数据质量、比较、应用和恢复入口。

验证命令：`pnpm test`、`pnpm lint`、`pnpm build`。浏览器验收使用隔离端口和合成记录，不读取/改写真实用户的学习数据库。依赖与算法以源码和锁文件为准，旧 AGENTS 中 FSRS v4、无测试、Supabase未接入等描述已经过时。
