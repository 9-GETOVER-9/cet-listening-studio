# FSRS 个人参数优化

用户授权完善个人参数优化及过时项目说明。复用现有干净维护工作区与依赖，在 feature/fsrs-personal-optimization 实现；不自动部署或推送。

## 决策

- 保持 ts-fsrs 5.4.1 / FSRS-6、90% 保留率和原学习步骤。
- 用现有库的 next_state / forgetting_curve 在 Web Worker 中做有界坐标搜索；这是本项目的优化方法，不冒称 Anki/fsrs-rs 的官方训练器，不声称全局最优。
- 不选服务端训练（新增服务与上传学习记录），也不选多线程 WASM（新增依赖及全站跨源隔离要求）。
- 听力主卡、难点本、阅读 538 分别建模；参数按账号或 guest 隔离，仅存本浏览器。训练不上传正文、音频或日志。
- 训练集与验证集按卡片分开，验证集不参与搜索；比较候选、当前参数及默认参数。只有验证误差低于当前和默认、训练目标低于当前，才可应用。
- 产品初始门槛：至少 20 张完整卡片、100 次跨日评分，且训练与验证均有成功及失败。跨日沿用 ts-fsrs 的 UTC 日期边界，不等于满24小时。这是保守的数据质量门槛，不是 FSRS 官方最低要求。
- 固定搜索预算及最多 5000 条评分，按完整卡片选取，避免截断卡片序列。超量时显式显示所用数量。
- 旧听力日志没有账号归属，默认排除；仅用户明确勾选认领时使用。连续记录数、最新复习时间及每条新增记录的序号必须与当前卡片一致。缺失历史、跨账号或云同步造成的缺口不补造。
- 难点本新增完整评分日志；阅读已有 owner 日志，排除 retry。新日志与评分状态在同一个数据库事务落盘。
- 显示可用记录、排除数量、训练进度、取消、失败原因、优化前后验证误差。采用渐进生效：应用、恢复默认均不改已有 D/S 或 due；参数从下一次评分使用，已有记忆估计随后续评分更新。历史重放用于训练及验证，不冒称已批量重算实际卡片。
- 参数采用有界的21元素有限数值数组；无效或存储损坏回退默认。应用持久化成功后才激活；账号切换、取消、离页时丢弃过期计算结果。
- 本地参数不在现有云端进度同步范围内，设置页明确告知；清除学习数据同时清除参数。

## 验收

测试完整/缺失/乱序/重复/跨账号历史；已知模拟记忆数据可得到验证损失下降；只成功或数据少不可训练；参数验证/持久化失败/恢复默认；实际评分与预览使用同一模型；Worker取消与失败不改变参数。全量 Vitest、ESLint、TypeScript、生产构建和浏览器实际操作。
