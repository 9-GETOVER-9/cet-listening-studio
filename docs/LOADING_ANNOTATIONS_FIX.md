# 2026-10-10 阅读加载与原句标注修复

阅读词库请求失败后，页面曾同时显示错误和持续加载提示；每次重新进入也会重复下载公共词库。现在公共词库通过验证后保存在当前应用内存中，并由 Workbox 按内容 revision 预缓存。再次通过站内导航进入无需重复下载；安装缓存后可离线打开。个人进度、FSRS 和批注仍按当前 owner 从原存储读取。

单次请求及响应体读取上限 8 秒，临时网络错误或服务端错误最多重试一次；失败显示中文提示与重新加载入口，停止加载提示。导航取消不会写入成功缓存或更新已离开的页面。首次访问与首次更新缓存仍需要网络。

设置页的原句标注按钮现在明确写“已开启 / 已关闭”。总开关关闭时提示三类标注暂停，保留子项选择，重新开启后恢复。用户截图的总开关实际为关闭状态。既有解析权限和精确匹配规则保持不变；不连续的短语仍显示在下方解析中。
