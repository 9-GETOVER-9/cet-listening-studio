# 原句发音与短语标注

个人中心 → 设置 → 原句标注，提供总开关、连读、弱读、短语三个独立开关，默认全部开启。总关闭保留子开关选择，刷新后保留本机浏览器设置；旧设置自动补齐默认值。

四六级及新概念学习、综合复习卡片和新概念跟读共用 AnnotatedSentence。当前使用蓝色词间弧线连接连读词，弱读紫色底，短语琥珀色底部括线；短语从整体两端标出边界，与发音重叠时仍保持同一括线。图例带文字说明。标注单词的鼠标提示保留来源解析和收藏提示，键盘/鼠标收藏不触发翻卡。本段为2026-10-10改版，已按用户确认部署；下方2026-10-09记录为旧版发布证据。

标注来自现有 AIAnalysis，不自动诊断音频。匹配连续完整英文 token，处理下划线、音标后缀、括号和箭头说明，保留原句和标点；不进行词形或非连续模糊匹配。无法可靠定位的内容仍显示在下方解析面板。原句标注受既有解析解锁规则约束。
