# 学习界面完善 · 2026-10-25

## 改动

- 首页整合续学、今日复习与三门课程书架；无学习记录时明确浏览课程，不默认跳到雅思。续学保留原句位置，按当前账号读取，拒绝外部或异常路径。
- 主导航改为今日、课程、复习、难点本、我的。新增 `/courses` 目录，原课程 URL 保持可用，课程子页同步高亮课程入口。
- 三张原创课程封面独立生成，600×800 PNG，位于 `src/assets/courses`。由 Vite 生成带内容哈希的资源路径，与现有 assets 发布流程兼容。课程图片访问后缓存，不加入 PWA 首次预缓存。
- 四六级默认按最新日期排序，可切换最早优先；保留完整筛选和每批 24 项的目录加载。题型及难度使用中文显示；课程查询失败可重试。
- 新概念每课将逐句精听、输入法跟读放在同一卡片。锁定册数可查看说明；会员按钮通往账号与会员，不保留无响应的开通按钮，也不将账号同步列为 Pro 专属权益。
- 听力卡片及综合复习的答案页固定重播、倍速和三个评分按钮。详细解析可展开；专注练习收起手机导航。保留评分提交、防重复操作、音频令牌、现有 AI 额度和复习调度。
- 难点本空状态提供课程入口，空分类禁用开始复习；达到收藏上限后，已有内容仍可阅读及复习。
- 个人中心分为学习概览、练习设置、账号与会员。修正游客试用状态文案，去除重复会员卡，给输入框补充标签。将原误称复习完成率的统计改为已学卡片覆盖口径；热力图包含今天及之前 83 天，并提供可展开的日期/次数表格。
- 个人统计按账号隔离异步结果，查询异常显示重试，不将读取失败表现为空收藏或零进度。
