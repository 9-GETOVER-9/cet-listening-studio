# 账号全模块同步

用户已授权开发、发布到既有站点和 GitHub；从当前生产提交 acf589f 建功能分支，保留现有私有测试导入。

## 设计

- 同源 `/api/learning-sync`，现有服务器 Python 标准库 + SQLite，数据在静态发布目录之外。通过 Supabase `/auth/v1/user` 验证会话，服务端决定用户 ID，拒绝客户端指定用户。仅传文字与进度；显式允许的数据集不包含任何音频、录音或 Blob。
- IndexedDB 持久化同步基线和待传变更，逐记录版本比较、操作幂等和删除墓碑；冲突按最近学习时间合并，同一笔记冲突按最近修改保留。日志使用独立操作 ID。离线继续本地学习，重连、回到页面和定时检查补传；不通过全量覆盖另一设备。
- 包含四六级/新概念卡片、难点本、评分历史、雅思听写/高频词错词与练习、阅读538含批注、新概念跟读结果和续练状态、个性 FSRS 参数。主库旧全局记录用本机账号快照隔离；切换账号先封存再恢复，访客不自动上传。
- 首次升级为已知当前账号保留本机旧进度，云端原 card_states/notebook 数据仅作首次迁移；后续统一新接口。允许多设备登录，移除旧的互踢守卫。录音保持浏览器本地数据库。
- 状态组件同时支持桌面、手机与“我的”页；明确提示本地录音不跨设备。
