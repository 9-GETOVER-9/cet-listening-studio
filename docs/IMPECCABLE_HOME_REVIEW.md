# 首页与课程入口评审

改动前首页在无到期复习时提供两个选课按钮，三张独立统计卡及大尺寸课程封面占据较多手机页面高度；课程总览和首页共用相同课程展示。页面 viewport 禁止缩放。精修保留现有配色和课程内容，以更紧凑的统计及课程入口突出续学、复习和选课。

使用 Impeccable 4.8.0 的源码检测与本地渲染页面检查；检测结果需结合实际设计判断，不把规则数量视为设计质量评分。基线扫描保存在本地忽略目录 `output/impeccable-baseline.json`。

手机首页与桌面课程页的渲染扫描指出的字号、标题层级及多余英文眉题已调整。剩余的奶白背景是用户明确选定的品牌配色；新手引导的图标提示属于引导弹窗，不在本次首页与课程入口精修范围，保留供后续单独评审。两项提示均未通过全局关闭规则掩盖。
